# Licensing

The application license is unresolved and blocks public distribution. Dependency
metadata and notices must be generated in CI. TeX Live package licenses,
redistribution terms, source obligations, font licenses, PDF.js, Tauri, and any
packaged native libraries require review during D1 and again before J5.

No managed TeX artifact may be published until its package manifest, licenses,
notices, checksums, and update provenance are recorded.
