# Roadmap

- M0: repository foundation and typed boundary.
- M1: safe project editing.
- M2: controlled local compilation.
- M3: PDF, diagnostics, and SyncTeX.
- M4: tolerant project intelligence.
- M5: Command Finder and `cryptocode` assistance.
- M6: notation profiles and conservative checks.
- M7: V0.1 security, compatibility, packaging, and release gates.
- M8: separate local PDF library.
- M9: optional local AI with reviewed diffs.
- M10: individually threat-modeled convenience features.

AI, RAG, PDF library, Git UI, remote editing, collaboration, WYSIWYG,
cloud synchronization, accounts, telemetry, and a plugin marketplace are outside
V0.1.
