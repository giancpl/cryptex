# Product

CrypTex provides a minimal Project | Editor | PDF workspace for cryptography
authors. It safely edits normal project folders, compiles them locally, displays
diagnostics and SyncTeX navigation, and offers deterministic LaTeX, `cryptocode`,
and notation assistance.

## Invariants

- Filesystem files are canonical; no proprietary document format or LaTeX dialect.
- Projects work with ordinary `latexmk` and remain Overleaf-compatible.
- Core editing and compilation are offline and account-free.
- `cryptocode` assistance targets the real package.
- Deterministic features precede optional AI.
- User-visible modifications require explicit intent.
