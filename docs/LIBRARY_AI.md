# Library and AI

The post-V0.1 library manages imported PDF copies, metadata, page-aware extraction,
and local FTS5 search. It is separate from project files and does not own `.bib`.

AI follows only after the deterministic core and library stabilize. Providers are
optional and disabled by default. Requests disclose their data scope, answers cite
local evidence, and file changes are proposed as diffs that require explicit
acceptance. Embedding indices are versioned and rebuildable.
